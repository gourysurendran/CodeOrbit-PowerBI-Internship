# Task 1 – Data Import & Cleaning in Power BI

## Overview

This project is part of the CodeOrbit Tech Power BI Internship. The objective is to import a sample sales dataset into Power BI and inspect its structure and data quality using Power Query Editor.

## Dataset

* **Dataset:** Sample Superstore
* **Source:** Tableau Sample Data
* **Sheet Used:** Orders
* **Total Rows:** 9,994
* **Total Columns:** 21

## Tools Used

* Microsoft Power BI Desktop
* Power Query Editor
* Microsoft Excel

## Work Performed

1. Imported the Sample Superstore Excel workbook into Power BI.
2. Selected the Orders worksheet.
3. Opened Power Query Editor.
4. Enabled Column Quality, Column Distribution, and Column Profile.
5. Changed column profiling to the entire dataset.
6. Inspected column data types and data quality indicators.
7. Applied the Power Query changes and saved the Power BI report.

## Data Quality Observations

The inspected columns showed:

* 100% valid values.
* 0% errors.
* 0% empty values.

The visible data types appeared appropriate. No manual value replacements or row removals were performed because the inspection did not identify issues requiring correction.
