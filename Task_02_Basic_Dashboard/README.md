# Task 2 – Basic Dashboard Creation

## Project Overview

This task involves creating an interactive sales performance dashboard using Power BI Desktop and the Sample Superstore dataset.

## Dataset

* **Dataset:** Sample Superstore
* **File:** `sample_-_superstore.xls`
* **Data used:** Orders sheet

## Tools Used

* Microsoft Power BI Desktop
* Power Query Editor
* DAX

## Dashboard Components

### KPI Cards

* Total Sales
* Total Profit

### Visualizations

* Sales by Category
* Sales by Region
* Sales by Segment
* Sales by Month
* Sales by Ship Mode
* Top 5 Best-Selling Products

### Interactive Filters

* Region slicer
* Category slicer

The slicers allow users to filter the dashboard and explore sales performance across different regions and product categories.
