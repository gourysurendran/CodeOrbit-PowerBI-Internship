# CodeOrbit-PowerBI-Internship
Power BI Internship Projects and Data Analytics Reports – CodeOrbit Tech

A collection of Power BI projects and data analysis tasks completed as part of the **CodeOrbit Tech – 2 Month Power BI Internship**.

This internship focuses on developing practical skills in Microsoft Power BI, data cleaning, data visualization, business intelligence, and report development.

* Microsoft Power BI Desktop
* Power Query Editor
* DAX (Data Analysis Expressions)
* Microsoft Excel
* GitHub
