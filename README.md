## Dataset

**Sample Superstore Dataset**

The Sample Superstore dataset is used for Power BI practice and sales analysis.

It contains sales-related information such as orders, customers, products, regions, quantities, discounts, and profits.

## Completed Work

### Task 01 – Data Import & Cleaning

* Imported the Sample Superstore dataset into Power BI.
* Used Power Query Editor to inspect the dataset.
* Checked column data types and data quality.
* Reviewed the applied transformation steps.
* Saved the Power BI report and supporting documentation.

### Task 02 – Basic Dashboard Creation

* Created a Superstore Sales Performance Dashboard.
* Added KPI cards for Total Sales and Total Profit.
* Created visualizations for category, region, segment, month, and ship mode.
* Identified the Top 5 Best-Selling Products.
* Added Region and Category slicers for interactive filtering.

## Learning Objectives

* Importing datasets into Power BI.
* Cleaning and transforming data using Power Query.
* Understanding data quality and data types.
* Creating interactive dashboards and visualizations.
* Developing DAX measures.
* Analyzing business performance and trends.
* Building multi-page reports with drill-through functionality.
